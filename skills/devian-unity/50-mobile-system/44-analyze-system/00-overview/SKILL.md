# 44-analyze-system — Overview

Status: ACTIVE
AppliesTo: v10

MobileSystem 샘플의 Analyze 시스템 개요다.
`AnalyzeManager`가 Firebase Analytics Custom Events 래핑을 담당한다.

이 스킬 그룹 책임:
- Firebase Analytics LogEvent 래핑
- 구간별 유저 동선 추적 이벤트 전송
- 플랫폼 공통(iOS/Android) 분석 이벤트 API 제공
